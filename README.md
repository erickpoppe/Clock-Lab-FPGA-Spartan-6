# Clock-Lab-FPGA-Spartan-6
Lab to understand how DCM and PLL work in Spartan-6 (XC6SLX45). 
Constraints are designed to work with Atlys Board from Digilent.  

----------------------------------------------------------------   
This code functions as an internal digital gearbox. It takes a single fast clock, synthesizes new speeds, swaps between them safely, and then slows them down so it can be eye watched.
